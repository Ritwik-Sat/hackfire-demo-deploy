# HackFire

Modern, professional, scalable multi-hackathon management system.

## Project Structure

- `frontend/`: React / Vite application
- `backend/`: Node + Express API
- `docs/`: API documentation and system diagrams

## Tech Stack

- **Frontend**: React, Vite, Vanilla CSS
- **Backend**: Node.js, Express, MongoDB (planned)
- **Real-time**: Socket.io
